# Prints dos Resultados dos Testes

Esta pasta reúne as evidências visuais da execução dos cenários de teste.

## Estrutura esperada

- 01-CT01-bloqueio-8-dias.png
- 02-CT02-limite-7-dias.png
- 03-CT05-bloqueio-reserva.png
- 04-CT06-bloqueio-renovacao.png
- 05-CT10-desenvolucao-bloqueio.png
- 06-CT11-dois-livros-atrasados.png

## Recomendação

Para cada print, registrar:

- identificação do teste;
- data/hora da execução;
- resultado obtido;
- link ou referência ao cenário correspondente.

Os arquivos de imagem devem seguir o padrão `NN-CTxx-nome-do-cenario.png`.
